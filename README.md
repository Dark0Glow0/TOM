# TOM: Tournament Operations Manager System

> 🚧 Work in progress

TOM is a Swiss tournament system for trading card games, inspired by the Pokémon TCG. It pairs players, records match results and calculates the standings.

## Features

- Scoring: win 3 points, tie 1 point, loss 0 points
- Automatic bye for an odd number of players
- Tiebreakers: OP% and OP OP%
- Data saved in the browser
